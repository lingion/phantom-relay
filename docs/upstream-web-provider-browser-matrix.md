## Phantom Relay 对照主调用链（按职责）

- **provider registration**：`bridge/web-providers.ts` → provider builder / model discovery → `providers/*-web-client(.browser).ts` + `streams/*-web-stream.ts`。
- **auth/session**：`providers/*-web-auth.ts` → Chrome/CDP attach or launch → cookies/localStorage/token → client constructor/request.
- **browser-backed transport**：browser client → Playwright/CDP page/context → page `evaluate`/fetch/XHR → provider SSE/NDJSON/DOM stream.
- **stream normalization**：provider stream factory → `processLine`/provider decoder → `emitDelta` → pi-agent `AssistantMessageEvent`; tool XML/JSON is accumulated into tool-call events.
- **tool injection loop**：`web-stream-middleware.ts` → `shouldInjectToolPrompt`/`getToolPrompt` → `extractToolCall`/`parseToolJson` → `wrapWithToolCalling` emits `toolcall_start/delta/end`, then tool result feedback is appended.
- **browser HTTP control**：`server.ts`/`server-middleware.ts` → `routes/dispatcher.ts` → `routes/index.ts` → `basic.ts`/`tabs.ts`/`agent.ts`; route context comes from `server-context.ts`, operations from `pw-tools-core.*` and `pw-session.ts`.
- **browser lifecycle**：`runtime-lifecycle.ts`/`server-lifecycle.ts` → `server-context.availability.ts` → `chrome.ts`/`cdp.ts`/`pw-session.ts`; profile/tab state is split across `server-context.*`, `profiles-service.ts`, `session-tab-registry.ts`.
- **browser agent actions**：`agent.act.ts` → `agent.act.hooks.ts`/`agent.act.download.ts` → `pw-tools-core.interactions.ts`/`downloads.ts`; snapshots: `agent.snapshot.ts` → `agent.snapshot.plan.ts` → `pw-tools-core.snapshot.ts`/`pw-role-snapshot.ts`.
- **security boundary**：`control-auth.ts` + `http-auth.ts` + `csrf.ts` + `navigation-guard.ts` + `request-policy.ts` + `paths.ts`/`output-atomic.ts`; these are mandatory Phantom Relay equivalents, not optional helpers.
