- 制定时间：2026-07-22T09:39:17+0800

- 目标：恢复并证明 GitHub 已知可用的豆包/DLM 非流式真实用户闭环，再逐步扩展普适站点特征、SSE、多轮、模型切换和并发。
- 最终成功定义：真实 GUI 浏览器 + 真实扩展 + 录制 input/send/response + 调用方真实 HTTP 非空回复。
- 静态审计、单元测试、queue=0、job claim、页面文字、手工 `/browser/result` 均不算最终成功。

## 0. 总纪律

1. 每次真实调用前读取：`docs/RECORDED_STANDARD.md`。
2. 每轮开始前创建时间戳归档，结束后补写结果。
3. 每轮只允许一个主假设、一个最小改动边界。
4. 任何修改前先确认 GitHub 基线和当前工作树差异。
5. 非流式未恢复前，冻结流式、并发、tool calling、网络拦截和上游审计。
6. 不使用 CDP 输入、点击、Enter 或手工 POST `/browser/result` 执行产品请求；CDP只能观察证据。
7. 不猜 selector、不自动发现、不扫描附近按钮、不替代录制 response。
8. 页面显示回答但调用方未收到回答，结论为失败，失败边界是回传/提取链。
9. 连续两轮同一假设失败，停止叠加补丁，回到根因调查。
10. 连续三轮同一边界失败，暂停该边界，回滚到最近可用基线并重新设计。
11. 不把“压榨到极致”理解为无休止堆任务；每个时间段都有可验证产出和停止条件。

- 以压力测试数量替代真实成功。
